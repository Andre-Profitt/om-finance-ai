## DL-0001 — 2026-04-24 — Collapse three parallel projects into one hero + embedded module + memo

**Decision.** The portfolio ships as (1) a deep Databricks-native hero build — Revenue Integrity Control Tower — with the Contract Economics Copilot embedded as an exception category, and (2) a standalone executive memo (Practice Acquisition & Performance Model). Not three parallel apps.

**Why.** GPT Pro review (2026-04-24) flagged that three-parallel-demos reads as "I built three prototypes," not "I can own a Lead TPM portfolio." One coherent product thesis with one deep artifact + executive framing tests the Lead TPM competency the JD actually screens for: roadmap ownership, charter, success metrics, stakeholder language, governance, financial business case.

**Considered.** Keeping three parallel builds; doing only the hero; doing only the memo.

**Reversal path.** If hiring feedback says "we wanted to see broader range," split the embedded Contract module back out as a standalone repo in Week 3; cheap reversal.

## DL-0002 — 2026-04-24 — 340B demoted from headline to scenario module

**Decision.** 340B logic lives as one scenario module inside the Contract Economics layer, not as a headline project or repo brand.

**Why.** 340B is under active HRSA policy reconsideration (rebate-model RFI) and live litigation. Framing the portfolio around "finding 340B leakage" reads as taking a policy-political side and risks alienating any 340B-adjacent stakeholder at McKesson or its customers. Framing it as "governance-first scenario module for a volatile policy environment" demonstrates exactly the judgment a Lead TPM needs.

**Considered.** 340B as headline (too political); cutting 340B entirely (loses the compliance-sophistication signal).

**Reversal path.** Scenario module can be expanded to headline if the interview process signals interest; content is all built either way.

## DL-0003 — 2026-04-24 — Business-outcome metrics replace vanity ML metrics

**Decision.** Eval harness headline metrics are precision@top-k, dollars-at-risk per reviewer hour, calibration, citation precision, abstention rate, override rate, payback sensitivity. AUC and MAPE do not appear in public artifacts.

**Why.** AUC on synthetic labels is non-credible to a hiring audience that knows synthetic labels were generated by the author. Business-outcome metrics force the TPM to reason about the full economics of AI adoption — the actual job.

**Considered.** Dual reporting (AUC + business metrics); AUC only (rejected); business metrics only (chosen).

**Reversal path.** AUC is still computed internally for model debugging; surfacing it externally is a one-line config change if ever needed.

## DL-0004 — 2026-04-24 — LightGBM + SHAP over fine-tuned BERT

**Decision.** Tabular risk scoring uses LightGBM with SHAP for local explanation. No fine-tuned transformer.

**Why.** The v2 plan proposed fine-tuned BERT; GPT Pro correctly flagged this as low-ROI for the TPM signal. LightGBM + SHAP is (a) state-of-the-art for tabular claims data, (b) auditor-defensible (SHAP is well-understood), (c) faster to train and iterate, (d) does not burn a week on fine-tuning infrastructure that does not advance the product thesis.

**Considered.** Fine-tuned BERT (rejected); XGBoost (equivalent; LightGBM chosen for training speed); logistic regression baseline (included as a comparator in the eval harness).

**Reversal path.** If claim-narrative text features prove material in Week 2 eval, add a small fine-tuned text classifier as a secondary feature source.

## DL-0005 — 2026-04-24 — Apply Week 0 with portfolio-in-progress landing page

**Decision.** Submit the McKesson application this weekend with a public landing-page URL and a "build in progress, weekly updates" commitment — not wait 2–4 weeks for a polished portfolio.

**Why.** The req is live. Waiting optimizes package-completeness and pessimizes req-availability — the latter dominates. Weekly ship cadence during the interview process is itself a signal of Lead TPM operating rhythm.

**Considered.** Apply Week 2; apply Week 4; don't apply until all four weeks complete.

**Reversal path.** None needed; if the application fails fast, the portfolio is still useful for the next comparable role.

## DL-0006 — 2026-04-24 — "Controllership-ready" replaces "auditor-defensibility"

**Decision.** All public artifacts use "controllership-ready" or "finance-reviewable" language. "Auditor-defensibility" does not appear in external docs.

**Why.** GPT Pro flagged "auditor-defensibility" as consultant-flavored. The finance-internal term for this quality is controllership. It reads as someone who has been inside a finance org.

**Considered.** "SOX-ready" (too narrow); "audit-safe" (too casual); "controllership-ready" (chosen).

**Reversal path.** Global find-replace, trivial.

## DL-0007 — 2026-04-24 — Real CMS ASP + NDC-HCPCS anchor; synthetic claims layer on top

**Decision.** The pipeline ingests real, public CMS ASP Part B quarterly pricing files and the CMS NDC-HCPCS crosswalk. Claims are synthetic but drug prices are real.

**Why.** All-synthetic data is dismissible to a hiring audience. Anchoring drug economics to the actual CMS files McKesson O&M Finance uses demonstrates domain fluency without touching PHI or proprietary contracts.

**Considered.** All synthetic (rejected); using HCUP or CMS Part B public claims (rejected: non-oncology-specific and heavier data licensing); anchoring drug prices only (chosen).

**Reversal path.** Claims data can be swapped for public HCUP extracts in a future iteration if needed for credibility.
